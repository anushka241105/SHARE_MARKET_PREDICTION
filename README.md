Stock Price Prediction (LSTM + FastAPI)

A simple and clean end-to-end Stock Prediction Web App built using LSTM, FastAPI, and a responsive frontend. Users can log in, select a stock, and get predicted prices based on historical data.

Features

LSTM-based stock price prediction

FastAPI backend with clean API routes

Login/Authentication system

Modern frontend (HTML + CSS + JS)

Real-time prediction visualization

How It Works

Data is preprocessed → scaled → sequenced

LSTM model predicts the next closing price

FastAPI serves the prediction through an API route

Frontend displays the result to the user
